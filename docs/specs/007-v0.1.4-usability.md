# v0.1.4 — 日常交互与可读性

Lifecycle: draft. Profile: strict. Date:2026-11-14. 用户要求此前列出的能力全部规划到0.1.4，不遗漏；本次只落版本范围、用户故事、技术/错误链路、AC→测试意图和tracker，不启动实现或发布。

## 目标、边界与承诺

让Pi用户更快读懂结果、找到证据、填写参数并查看产物。下列C01–C14全部纳入0.1.4必选规划，按W1–W7拆分；优先级决定先后，不是移出版本的理由。Video/AudioPlayer明确保留。CopyAction是能力，ArtifactPreview可由专用部件或受审组合实现；规划覆盖不要求每项都新造一个catalog类。

新增R01–R08是对“还有什么有用组件”的候选建议，不自动加入必选交付或改变已确认14项。实施前逐项走严格Gate1/2并关闭设计决策；规划覆盖审查GO不等于实现GO。任何删减必选范围必须记录用户明确变更，不能用推迟媒体或静默条件替代版本验收。

IN：已列组件/交互、匹配catalog与渲染实现、输入/事件/资源/恢复边界、Node24及Git/local分发。OUT：自动执行浏览器文本、任意文件/URL读取、通用RPC/动态插件市场、远程托管、新模型/额外模型按流片调用、npm registry发布、自动修改真实用户安装。

## 不放宽的共同约束

- **Node 24.x only**：engine `>=24.0.0 <25.0.0`、`.nvmrc=24`、所有当前安装/开发示例先`nvm use 24`。Pi当前验证基线1.5.0；SDK升级必须另有差异证据，不能为了接组件隐式升级依赖。
- 沿用现有32KiB source、256KiB snapshot、64KiB POST body、64 components/surface、4 surfaces、depth16、8 SSE clients、1024 event IDs/epoch及256KiB SSE queue限制；既有JSON节点/集合、日志与coding记录边界同时有效。新部件的单项上限不保证所有上限乘积同时可容纳，组合仍受全局预算原子拒绝。
- 保持旧catalog/snapshot可恢复；新能力进入明确的新版本catalog（初始方案workbench-v1），不偷改旧catalog的Text纯文本契约，不运行时下载未经审查schema。新旧catalog schema/模型提示/浏览器实现必须一致。
- 列表/Markdown/Modal/折叠部件都必须遍历全部child slots、检查树/绑定/上下文；本地开合/复制/过滤与发送Pi意图区分；动作仍由epoch+结构revision、sourceComponentId和既有事件校验保护。
- 组件状态/进度来自实际Pi工具/生命周期；没有证据不标记成功，没有分母不报百分比。数据更新不得覆盖未提交输入；断线、分支/会话切换、toggle、reload、取消和shutdown均有资源回收/旧回调无效证据。
- 每次功能验收使用真实浏览器和生产包；实际模型环节仅允许现有AgentPlan `volcengine-ark/glm-5.3-flash`，无默默回退。增量日志/状态不逐片调用模型。已知上游Zod风险继续披露，不称审计干净。

## 三轮走查摘要

| 用户路径 | 进入 → 服务端/状态 → 浏览器 → 回到Pi | 必须覆盖的失败路径 |
| --- | --- | --- |
| W1 | a2ui_render有界列表/表格 → shared schema+tree/snapshot admission → 本地滚动/排序/筛选 → 可选行操作通过现有Button事件 | 过量行列、非原始单元格、重复ID、结构替换、过滤后无结果/仍在加载区分 |
| W2 | 模型提交代码/受限Markdown → 字节/行/语法白名单 → 转义显示或本地复制 → 复制不触发工具 | HTML/URL注入、复杂Markdown、超长/控制字符、clipboard拒绝、旧Text行为回归 |
| W3 | 受审child树 → 不变的组件身份/数据模型 → 本地Details/Accordion开合 → 内部动作按原授权发回 | 隐藏输入、焦点/键盘、live批次、结构替换、滚动与选择损坏 |
| W4 | 真实tool start/update/end/agent生命周期 → 有界状态归约 → badge/进度 → 用户选择下一步仍回Pi | 乱序/重复、取消/错误、无总量、旧epoch/timer、流结束/失联与成功混淆 |
| W5 | 官方Modal/Icon schema → 新child槽和有限图标名校验 → 焦点/图标本地渲染 → 显式事件 | 伪造隐藏上下文、缺失子节点、未知图标/远程字体、Escape/焦点返回、过时提交 |
| W6 | Pi权限内注册产物 → 有界会话能力/授权资源路由 → ArtifactPreview/Image → 用户可请求重新发布失效产物 | 路径逃逸/源替换、类型/大小伪装、过期ID、跨会话访问、CSP、关闭中途读取、恢复只显示不可用 |
| W7 | 复用W6产物源 → 有界单Range/stream route → 用户播放Video/AudioPlayer → 关闭/取消释放 | 多Range/非法range、断连/慢读、格式失败、自动播放、旧会话继续读、句柄/缓存泄漏 |

## 媒体/产物的严格设计门禁（W6/W7）

这些门禁是必选范围的前置工作，不是把媒体移出0.1.4。当前服务没有文件服务、CSP为img-src none，故不能仅给官方组件加白名单。

- D1 来源/权限：冻结Pi侧产物注册契约、授权根目录和能力撤销规则。初始方案只接受当前任务已授权的产物，HTTP请求仅凭opaque ID读取已注册资源，禁止浏览器提交任意路径/外链；真实路径、符号链接、文件替换/变化、文件句柄与缓存的边界必须独立审查，不宣称仅靠前缀检查即可安全。
- D2 预算初案：最多16个注册产物；图片每个10MiB，音/视频每个64MiB，总缓存128MiB，媒体并发流2；单Range、流式背压与取消。媒体字节不放入A2UI JSON，不借此放宽source/snapshot/SSE边界。各值与缓存实现须在Gate1冻结，之后有边界/泄漏测试。
- D3 浏览器与格式：img-src/media-src只允许本实例授权来源，禁止任意外链/file/data/SVG活动内容；图片首版PNG/JPEG/WebP。冻结可由目标Chromium真实播放的小型音视频fixture及MIME/编码能力，不能把仅渲染标签当作播放验收。
- D4 生命周期/恢复：明确暂停/树/会话/reload/退出时撤销和停止流；仅清理本插件拥有的缓存/句柄，不删除用户产物。持久快照保存有界标识/元数据，不保存私钥或任意文件读取能力；失效资源显示不可用并保留其他UI，不自动读取历史路径。异常退出缓存治理、重放/Range错误和文件变化均须有设计结论。

Gate1未关闭D1–D4时，不实现资源路由或开放媒体catalog；已完成文本组件不构成媒体门禁豁免。具体注册接口/缓存/格式决策写入本规范的受审补充，拒绝“代码先写，安全以后补”。

## 发布/兼容验收

RLS-01：C01–C14及T01全部有通过的AC/测试和独立代码审查，或用户明确变更版本范围；候选R项不作为假通过/阻塞替代项。RLS-02：旧Basic/coding/live snapshots、旧输入/actions、断线/慢客户端和有界资源回归；不通过时原UI不被半更新。RLS-03：Node24真实Git/local生产安装、预构建资源/legal/CHANGELOG完整、实际Pi浏览器交互/恢复/清理/回退，真实模型只用GLM。RLS-04：v0.1.4 tag/asset/publication是另一步授权/回执，本规划不创建它；现有0.1.0/1/3保持不可变。

## 新增候选（不混为官方组件或必选交付）

| ID | 候选 | 价值 | 实现判断 |
| --- | --- | --- | --- |
| R01 | TreeView / Breadcrumbs | 文件树、调用层级、任务位置一目了然 | 自定义；选择只发送当前作用域内的意图，不直接读文件；限定节点和深度 |
| R02 | SearchablePicker / ComboBox | 从较长分支、文件或选项列表快速选中 | 先评估TextField+ChoicePicker组合；键盘筛选且值必须属于已授权选项 |
| R03 | KeyValueView / MetricCard | 把环境、构建摘要、耗时和参数压缩为清楚的键值信息 | 优先复用现有Card/Row/Column/Text模板，不先造新catalog类型；数值有来源 |
| R04 | InlineValidation / FormErrorSummary | 错误直接定位到具体字段和原因 | 客户端反馈配合服务端复验；不把模型给出的checks当授权或放开任意函数 |
| R05 | Callout / EmptyState / Skeleton | 分清失败、无结果、未执行与加载中，并给恢复动作 | 可先做现有组件组合；状态从实际请求/工具生命周期推导 |
| R06 | ActivityTimeline | 回看工具执行顺序、耗时和失败节点 | 共用真实事件源和有界窗口；不建立无限历史库或编造时序 |
| R07 | EvidenceLink / SourceLocation | 从结论定位文件行、测试记录或来源 | 携带固定来源ID/位置；由Pi确认处理，浏览器不开放任意file://或路径读取 |
| R08 | CommandPalette / ActionBar | 键盘查找当前可用动作，减少鼠标往返 | 只引用当前epoch/revision的现有动作；不增加直接命令执行权限 |

## 回退与风险

初始回退基线为已发布v0.1.3：关闭/移除新包注册，撤销新资源能力并释放本插件资源，保留Pi历史/凭据和用户文件。新组件快照在旧包可能被跳过，不能承诺无损逆向UI恢复。Node24要求不回退；媒体/权限相关实现一律strict全门禁。
