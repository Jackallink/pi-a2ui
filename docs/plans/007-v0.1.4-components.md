# v0.1.4 component delivery plan

> User has authorized detailed design/independent review, then implementation by Codex in issue10→16 order after scoped GO. Use executing-plans for the admitted slice; no stopped Pi worker restart. Publication is not implied.

**Goal:** 完整覆盖C01–C14七组日常交互能力，提升Pi阅读/比较/输入/状态/产物检查体验。

**Architecture:** 沿用显式a2ui_render、共享schema、受限catalog、Lit实现、epoch/revision事件和有界SSE数据更新。新媒体通过单独受审的会话产物能力进入，不能变成任意文件服务。CopyAction/组合部件优先复用现有机制。

**Tech stack:** Node24.x only、Pi1.5当前基线、锁定A2UI SDK、TypeScript/Lit、node:test/Playwright；模型验收仅AgentPlan GLM。

**Spec:** ../specs/007-v0.1.4-usability.md（唯一范围）；walkthrough: ../walkthrough/v0.1.4/walkthrough.md。

## 范围/依赖/实施顺序

版本总范围是七组，不把分批当成七个版本。阶段A：W1/W2/W3，先解决读结果、读代码、长内容，并交付T01键值/对比/步骤/下一步动作组合示例。阶段B：W4/W5，真实状态及聚焦详情；W4延续现有native/live生命周期，W5依赖完整slot遍历。阶段C：W6先关闭D1–D4并交付产物/Image，再由W7复用其能力交付Video/AudioPlayer。各组设计可提前推进，资源实现不能越过门禁。
