# v0.1.7 — practical DX and skill fixes

Requires **Node24.x only** (`nvm use 24`), Pi>=1.5.0. Git/local distribution, no npm publication. From the intended Pi project:

```sh
nvm use 24
pi install -l --approve git:github.com/Jackallink/pi-a2ui@v0.1.7
```

`-l` means project scope; omit it intentionally for user-wide installation. `--approve` trusts that project for this command. Before changing Git/local source, inspect `pi list` in both scopes and remove obsolete registrations in their original scope so a tool is not loaded twice. Pinned tags do not jump to new versions on update/reload: select the new ref explicitly. Package discovery loads the extension and pi-a2ui skill together; no separate global skill/CLI install is needed. Ready browser/helper assets ship in Git/archive, with no consumer TypeScript/tsx/esbuild build.

For an existing local checkout or downloaded archive, install production dependencies first, then register its absolute path from the intended Pi project:

```sh
nvm use 24
npm install --prefix /absolute/path/to/pi-a2ui --omit=dev --ignore-scripts --legacy-peer-deps
pi install -l --approve /absolute/path/to/pi-a2ui
```
