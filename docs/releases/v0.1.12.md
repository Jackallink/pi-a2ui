# v0.1.12: render polish

Canvas rendering polish per issue #67 / Spec028, without changing any data, event, draft, sorting or permission contract:

- `Chart` gains a non-color series identity layer: legend swatches and deterministic line styles (dash `none`/`7 3`/`2 3`/`11 4` with circle/square/triangle/diamond point markers), so series stay distinguishable in grayscale or for color-blind readers. Axis ticks render in the monospace token with a measured per-label gutter (40px floor, actual font-metric width + 12 padding) replacing the character-count estimate.
- `Chart` x labels gain a bounded wrap fallback: when no full single-line label fits its slot, labels wrap to at most 3 lines (full text kept in `<title>`), the last label reserves a full-width right-edge column so columns never collide (adjacent gap ≥6 viewBox units), and the viewBox height grows with the deepest wrap instead of discarding every label.
- `DataTable` scroll regions are named focusable regions (`tabindex=0`, `role=region`, caption-derived label) making keyboard arrow scrolling a contract.
- The generic canvas button reset no longer overrides SDK `Tabs` active or `ChoicePicker` chip selected states; hover styling is scoped off the active tab.
- Shipped tests extended: corrective regressions (F1–F4) plus an acceptance suite covering 32-component style coverage with contrast ratios, 200%-zoom proxy and physical-equivalent rendering, keyboard/modal/pause/inert flows and dynamic chart updates.

The remaining Spec028:63 item — an actual desktop 200% browser-zoom operation record — is a human follow-up tracked in [Check133](../checks/133-render-polish-acceptance.md)/[Check134](../checks/134-v0112-release.md); headless CI provides physical-equivalent and CSS-zoom-proxy evidence only. Report issues from actual use as they appear.

## Installation

Requires **Node24.x** and Pi>=1.5.0. Distribution is Git/local, not npm. In a project with no other active registration of this package:

```sh
nvm use 24
pi install -l --approve git:github.com/Jackallink/pi-a2ui@v0.1.12
```

`-l` is project-local. For an existing global registration, update it globally by omitting `-l`; do not add a second registration. Restart Pi under Node24 after an upgrade, then use `/a2ui-status` and `/skill:pi-a2ui`. Ready assets are included; consumers do not build TypeScript or browser code.
