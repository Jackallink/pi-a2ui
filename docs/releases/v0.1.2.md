## Install after publication

From your intended Pi project directory, download `pi-a2ui-0.1.2.tgz` and `SHA256SUMS` from the matching [GitHub Release](https://github.com/Jackallink/pi-a2ui/releases/tag/v0.1.2), after publication.

```sh
shasum -a 256 -c SHA256SUMS
mkdir -p "$HOME/.local/share/pi-a2ui/0.1.2"
tar -xzf pi-a2ui-0.1.2.tgz -C "$HOME/.local/share/pi-a2ui/0.1.2"
npm install --prefix "$HOME/.local/share/pi-a2ui/0.1.2/package" --omit=dev --ignore-scripts
pi install -l --approve "$HOME/.local/share/pi-a2ui/0.1.2/package"
```

Pi's `--approve` trusts project-local files for this command; run it from a project you trust. Reload Pi and run `/a2ui`. Built browser assets and full third-party licenses are included. Use one active pi-a2ui registration per Pi instance; preserve unrelated packages/settings/credentials. Keep the intended Pi project as your working directory throughout; this example chooses current-project scope.
