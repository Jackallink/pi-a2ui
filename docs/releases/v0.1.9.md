## Install or update after publication

Choose one active registration scope. An existing global package plus another local registration can conflict on `a2ui_render`; do not register the same extension twice in one Pi session.

```sh
nvm use 24
# Project-local Git registration:
pi install -l --approve git:github.com/Jackallink/pi-a2ui@v0.1.9
```

A local checkout can be registered with `pi install -l --approve /absolute/path/to/pi-a2ui`. Production assets and the skill helper are prebuilt; end users do not run a TypeScript/esbuild build. In Pi use `/reload`, then `/a2ui-status`; `/skill:pi-a2ui` explicitly loads the component/template guidance. This procedure does not authorize an automatic global installation replacement.
