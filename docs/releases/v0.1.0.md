## Delivered behavior

An explicit Pi tool compiles complete A2UI Express into validated UI, serves bundled official renderer assets on loopback, and returns browser form actions to the same Pi conversation. Includes six basic components, three commands, atomic replacement, branch restoration, reconnection, event/context authority and lifecycle cleanup.

## Restore and rollback

Check out `v0.1.0` for this source checkpoint; verify the downloaded archive using the release SHA256SUMS. Install the archived package from a version-specific directory so future versions do not overwrite it. Run `/reload` after switching Pi package registration. Remove only the relevant project/user package registration to roll back; keep session data and credential files. Current-branch UI snapshots are validated during restoration, and incompatible records are ignored rather than executed.
