## REL-01 — P1: bundled dependencies lack complete redistribution license material

The initial `pi-a2ui-0.1.0.tgz` contains 15 files and only the project's MIT LICENSE. `dist/client.js` includes redistributed Lit/A2UI and other dependency code; retained esbuild legal comments contain SPDX identifiers or license URLs rather than the full applicable conditions/disclaimers. For example, installed `node_modules/lit/LICENSE` requires its copyright, conditions and disclaimer in redistribution, and installed A2UI/signal-polyfill Apache licenses section 4(a) require a copy of the license. A later dependency installation does not make the downloadable prebuilt bundle self-contained in this respect.

Required repair: package complete third-party license/notice material for the actual bundled packages, preserve upstream copyright notices, regenerate the archive/checksum and verify inclusion. Preserve the repository owner's MIT LICENSE. This is a packaging repair; it requires no runtime feature expansion.

An offline esbuild `write:false`/metafile inspection identified bundle inputs from: `@a2ui/lit`, `@a2ui/web_core`, `@lit/context`, `@lit/reactive-element`, `@preact/signals-core`, `lit`, `lit-element`, `lit-html`, `redos-detector`, `signal-polyfill`, `signal-utils`, `validate-color`, `zod`, and `zod-to-json-schema`.
